# معماری

PnuNews یک برنامه ESM مبتنی بر Node.js 24، MariaDB و فایل‌های ثابت بدون مرحلهٔ build است. نقطهٔ ورود تولید `server.js` است؛ پیکربندی از متغیرهای محیطی خوانده می‌شود و مهاجرت‌ها پیش از پذیرش درخواست اجرا می‌شوند.

این سند در milestoneهای بعدی با مرزبندی ماژول‌ها، API، سیاست دسترسی و چرخهٔ انتشار تکمیل می‌شود.
