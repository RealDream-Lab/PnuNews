# تصمیم‌ها

- رابط کاربری و راهنمای مالک فارسی خواهد بود؛ شناسه‌ها و کد انگلیسی می‌مانند.
- Node.js 24 و ESM انتخاب شدند تا با کانتینر تولید سازگار باشند و نیاز به مرحلهٔ build نباشد.
- برای توسعه از MariaDB 12.3 در Docker Compose و گذرواژهٔ ثابتِ صرفاً توسعه استفاده می‌شود؛ این گذرواژه برای تولید نیست.
- بارگذاری `.env.dev` با یک loader کوچک داخلی انجام می‌شود تا وابستگی dotenv اضافه نشود.
- وابستگی‌های تولید دقیقاً نسخه‌بندی شده‌اند و به فهرست مجاز brief محدودند: Express برای HTTP، mysql2 برای MariaDB، Busboy برای آپلود جریانی، Sharp برای پردازش تصویر، sanitize-html برای پاک‌سازی HTML و qrcode برای QR. نسخه‌های اولیهٔ mysql2، Sharp و sanitize-html با نسخه‌های امن‌تر جایگزین شدند؛ `npm audit --omit=dev` بدون آسیب‌پذیری گزارش می‌دهد.
- فونت‌های Vazirmatn Regular/Medium/Bold از دارایی‌های پروژهٔ محلی PnuCard کپی شدند تا بارگیری فونت به سرویس خارجی وابسته نباشد.
- M0 مهاجرت‌رانر را با جدول نسخه‌ها ایجاد می‌کند؛ طرح کامل جداول در M1 افزوده می‌شود.
